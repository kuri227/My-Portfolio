# Kuri's Portfolio

ポートフォリオURL：https://kuri-portfolio.pages.dev/

**Kuri** のポートフォリオサイトです。  
Web・AIの学習、制作物、Kosen Tech Clubでの学習支援、インターンでの課題整理・提案経験をまとめています。

---

## 特徴 (Features)

* **データ駆動設計 (Data-Driven)**
    * 作品・経歴・スキルの情報は `PORTFOLIO_DATA` から管理し、HTML 側の構造は最小限に保つことで、内容追加が簡単にできます。
* **分離されたスタイル管理**
    * 共通の見た目に関するスタイルは [styles.css](styles.css) に切り出し、HTML の可読性とメンテナンス性を向上させています。
* **根拠を分けて伝える情報設計**
    * 制作物、カリキュラムでの実践、レビュー・支援活動を区別し、経験の根拠が分かるようにしています。
* **フルレスポンシブ (Responsive)**
    * カスタムCSSでスマートフォンからPCまでの表示を調整し、ネイティブの `dialog` 要素を使ったプロジェクト詳細表示を実装しています。
* **アクセシビリティ**
    * スキップリンク、キーボード操作、フォーカス表示、モーション軽減設定に対応しています。
