# Kuri's Portfolio

ポートフォリオURL：https://kuri227.github.io/My-Portfolio/

**Kuri** のポートフォリオサイトです。  
AI、Webアプリケーション、ハードウェア領域を横断したこれまでの制作物や、チーム開発での経験、スキルセットをまとめています。

---

## 特徴 (Features)

* **データ駆動設計 (Data-Driven)**
    * 複雑なHTMLを直接編集する必要はありません。ファイル下部の `PORTFOLIO_DATA` (JSONライクなオブジェクト) を書き換えるだけで、タイムライン、スキルセット、作品一覧のUIが自動的に生成・更新される拡張性の高い設計を採用しています。
* **シングルファイル構成 (Single File)**
    * HTML、CSS、JavaScriptを `index.html` 1つのファイルに統合しており、デプロイや管理が極めてシンプルです。
* **モダン＆クリーンなUI**
    * 過剰な装飾を排し、余白とタイポグラフィを活かしたエンジニアらしいソリッドなデザインに仕上げています。
* **フルレスポンシブ (Responsive)**
    * Tailwind CSSを活用し、スマートフォンからPCまであらゆるデバイスで美しく表示されます。SPAライクなシームレスな詳細モーダルを実装しています。
